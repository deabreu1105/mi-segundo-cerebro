# Abstracción

## Definition
La **Abstracción** es el pilar del pensamiento computacional mediante el cual se ocultan o ignoran los detalles secundarios, irrelevantes o ruidosos de un problema para centrarse exclusivamente en la información esencial y en las características estructurales relevantes.

## Key Ideas
- **Filtrado de Ruido:** Elimina aspectos decorativos o circunstanciales para aislar el modelo conceptual subyacente.
- **Creación de Modelos:** Permite construir representaciones simplificadas (diagramas de clases, esquemas de BD, interfaces) que capturan la esencia del dominio de negocio.
- **Gestión de la Complejidad:** Facilita trabajar a diferentes niveles de elevación (desde alto nivel de negocio hasta bajo nivel de implementación).

## Applications
- Definición de API Contracts y tipos/interfaces TypeScript/Java.
- Diseño de diagramas de dominio y casos de uso.
- Formulación de especificaciones de requerimientos para LLMs.
