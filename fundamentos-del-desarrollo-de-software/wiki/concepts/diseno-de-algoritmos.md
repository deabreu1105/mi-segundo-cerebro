# Diseño de Algoritmos

## Definition
El **Diseño de Algoritmos** es el cuarto pilar del pensamiento computacional y consiste en la formulación del plan paso a paso, finito, preciso y estructurado para resolver un problema o ejecutar una tarea determinada.

## Key Ideas
- **Propiedades Fundamentales:**
  1. *Secuencia:* Flujo lógico ordenado paso a paso.
  2. *Precisión:* Instrucciones inequívocas sin ambigüedad.
  3. *Finalización:* Garantía de terminación tras un número finito de pasos.
- **Herramientas de Repesentación:**
  - *Diagramas de Flujo:* Representación gráfica normalizada (óvalos para inicio/fin, rectángulos para procesos, rombos para decisiones, flechas para flujo).
  - *Pseudocódigo:* Expresión formal en lenguaje natural estructurado sin atarse a la sintaxis estricta de un lenguaje de programación específico.
- **Auditoría Previa:** Permite validar la corrección lógica antes de escribir código o comprometer recursos técnicos.

## Applications
- Planificación lógica de módulos y endpoints.
- Comunicación de lógica de negocio entre diseñadores, analistas y programadores.
- Elaboración de diagramas Mermaid para documentación del sistema.
