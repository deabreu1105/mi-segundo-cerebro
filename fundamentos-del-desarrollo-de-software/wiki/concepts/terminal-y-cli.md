# Terminal y Línea de Comandos (CLI)

## Definition
La **Terminal y Línea de Comandos (CLI - Command Line Interface)** es la interfaz de texto que permite interactuar directamente con el sistema operativo y la infraestructura de servidores ejecutando comandos específicos, eliminando la sobrecarga visual y la latencia de las interfaces gráficas (GUI).

## Key Ideas
- **Motor de Automatización:** Es la herramienta principal para la orquestación de scripts, compiladores, herramientas de build, contenedores Docker y pipelines de integración continua (CI/CD).
- **El Panel de Control de la IA:** Mientras la IA actúa como copiloto generando código ("qué"), la terminal otorga al desarrollador el control sobre el entorno de ejecución ("dónde" y "cómo").
- **Anatomía de Comandos:** Se estructura universalmente como `comando [opciones] [argumentos]` (ej. `ls -lh /var/log`).

## Applications
- Administración de servidores Linux/Unix en la nube y contenedores.
- Ejecución de scripts de despliegue y herramientas de compilación.
- Navegación rápida por el árbol de archivos sin interfaz gráfica.
